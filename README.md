# Ashare-industrial-chain

主流炒股软件产业链库合集 —— KaiPanLa / TongDaXin / JiuYanGongShe 三源数据。

## 库内容

| 文件 | 来源 | 规模 |
|---|---|---|
| kaipanla.json | KaiPanLa | 15,498 条 / 223 个题材 |
| tdx.json | TongDaXin | 17,513 条 / 152 条产业链 |
| jiuyan.json | JiuYanGongShe | 38,379 条 / 1,246 张产业链图谱 |

每条记录包含：
- **产业链层级路径**（如 `光伏 / 电池片 / HJT电池`）
- **成分股名称与股票代码**
- **题材出处**（来自哪个产业链图谱）

## 用途

支持输入**个股代码或名称反查**其在三大来源中的全部产业链归属，
一眼看清一只股票横跨哪些题材链条，是量化交易强有力的工具。
